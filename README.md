# VRCボイスペット

VRChat用のボイス連動ペットギミック向けプログラムです。

マイクから取得した音声を利用し、VRChat内のペットギミックなどと連携して使用することを目的としています。

## ダウンロード

最新版の実行ファイルは GitHub Releases からダウンロードできます。

[Releases](../../releases)

Windowsでは、ダウンロードした `VRC_VoicePet.exe` を実行してください。

## 特徴

- マイクから音声を取得
- 音声認識による文字・発話の取得
- VRChatとの連携
- VRChat内のペットギミックなどへの利用
- 設定した内容の保存
- Windows向け実行ファイルを提供

## 動作環境

- Windows 10 / 11
- VRChat
- マイク

## 使い方

1. Releasesから最新版の `VRC_VoicePet.exe` をダウンロードします。
2. `VRC_VoicePet.exe` を起動します。
3. 使用するマイクを選択します。
4. 必要な設定を行います。
5. VRChatを起動します。
6. 対応するギミックと組み合わせて使用します。

詳しい使い方については、今後追加していきます。
